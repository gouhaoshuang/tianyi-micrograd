## 2. 第一版的范围

目标是与参考项目相同层次的 **Python 标量自动求导引擎与小型全连接网络**：

- 一个 `Value` 保存一个数值、一个梯度和计算历史。
- 前向计算动态建立有向无环图。
- 用局部导数、链式法则和逆拓扑顺序完成反向模式自动微分。
- 用 `Module`、`Neuron`、`Layer`、`MLP` 组织参数与计算。
- 用自己写的梯度更新循环完成训练。

首版不引入 Tensor、多维广播、GPU、C++、自动优化器框架或 Transformer。TianLLama 提供的是教学方式参考，不要求把它的工程层次搬过来。主线完成后再选择扩展方向。

`tianyi_micrograd.engine` 不引入 torch 或 NumPy；`nn` 只需要标准库 `random` 和自己的 `Value`。PyTorch 只在可选对照测试中出现。

## 3. 为什么按这个顺序拆课

直接抄完两个核心文件，很容易混淆四件事：

1. **前向计算**：这一步得到的数值是多少。
2. **局部导数**：当前运算的输出对直接输入有多敏感。
3. **梯度传播**：最终目标对当前输出的敏感程度，如何传到输入。
4. **调度顺序**：共享节点的所有下游贡献，何时才收集齐。

因此先只有前向图，再手动调局部反传，最后实现自动调度。神经网络层建立在已经验证过的引擎上，训练循环建立在已经验证过的参数管理上。

最初先展开第 00、01 课，再逐步补齐后续内容。按用户 2026-10-24 的要求，第 07～10 课已一起编写完成。文档齐全后仍按实际代码进度逐课实现、验证；后续解释与修订继续以用户亲手写出的版本为准。

## 4. 各课的实现边界与验收

以下是各课的范围与验收设计，不是要求现在把全部内容一次实现。详细步骤见课程目录中的对应文档。

### 第 00 课：学习准备与梯度直觉

- 默认激活 conda `agent`，确认解释器路径。
- 用普通 Python 数值计算 `L=(a*b+c)*f`。
- 手算偏导数，再用中心差分近似。
- 理解 `data` 与 `grad` 对应两种不同的信息。
- 验收：在 `(a,b,c,f)=(2,-3,10,-2)` 时，`L=-8`，四个偏导数为 `6,-4,-2,4`。

本课只做终端实验，不需要创建源码文件。

### 第 01 课：Value 与前向计算图

- 用户创建包、`engine.py` 和第一份测试。
- 实现 `__init__`、`__repr__`、仅支持两个 `Value` 的 `__add__` 和 `__mul__`。
- `_prev` 记录输入对象，`_op` 记录运算名称。
- 验收：链式表达式数值正确；结果节点是新对象；输入对象未被修改；同值对象仍是不同节点。

本课尚无自动求导，也不支持 `Value + 数字`。

### 第 02 课：局部梯度与手动反向传播

- 增加叶节点的空 `_backward`，以及加乘运算各自的反传闭包。
- 解释 Python 的嵌套函数、闭包和函数对象赋值。
- 给最终输出设置 `grad=1`，手动按正确顺序调用反传。
- 加法局部导数为 `1,1`；乘法局部导数为“另一个输入的数值”。
- 验收：得到第 00 课的四个梯度；`x+x`、`x*x` 的梯度分别为 `2`、`2*x.data`。

这里必须解释为什么用 `+=`：一个节点可通过多条路径影响目标，同一次反传的各条贡献需要相加。即使 `_prev` 将 `x*x` 的输入去重，乘法闭包仍须贡献两次。

### 第 03 课：拓扑排序与自动反向传播

- 实现带 `visited` 的后序遍历，先得到输入在前、输出在后的拓扑列表。
- 输出梯度设为 `1`，逆序执行每个节点的 `_backward()`。
- 解释 `_prev` 的集合顺序不固定，但合法拓扑顺序不唯一。
- 验收：链、重复操作数、分叉汇合图都正确。
- 重点例子：`u=x*2`、`L=u*u+u`，`x=3` 时 `L=42`，`x.grad=26`。实际测试在尚无数字混算时使用 `Value(2.0)`。

必须区分“同一次反传中多路径的梯度累加”和“多次调用 backward 的累积行为”。参考实现不会自动清空整张图；复用旧图反传会受残留中间梯度影响，不能简单解释为“每次把正确梯度再加一次”。主线训练每步重新前向建图，并在反传前清空参数梯度。

### 第 04 课：幂运算、ReLU 与 Python 运算协议

- 增加常量包装，使 `Value + 数字`、`Value * 数字` 可用。
- 增加 `__pow__`、`relu()`，再组合负号、减法和除法。
- 增加左右运算协议，解释 `2+x`、`2-x`、`2/x` 和 `sum()`。
- 幂指数只支持普通 `int/float`，与本机参考实现对齐。
- 验收：正反向混合运算；非零点的正负幂；ReLU 的正区、负区和零点约定。

ReLU 在零点不可导，本项目沿用参考实现，取反传贡献为 `0`。不要用零点的中心差分强求一致。除零、负底数的非整数幂等不属于第一版的通用支持范围。

还要解释：没有实现 `__iadd__` 时，`c += ...` 使用加法结果重新绑定名字；它不等于在旧节点的 `.data` 上原地累加。

### 第 05 课：梯度校验与参考实现对齐

正确性证据分三层，前两层是主线验收：

1. 手算：覆盖每种局部导数和共享节点，预期数值独立写出。
2. 有限差分：用普通浮点函数检查组合表达式，多变量逐一扰动；避开不可导点和非法定义域。
3. 可选 PyTorch 对照：参考原仓库两个测试的表达式，以 `float64` 比较输出及叶节点梯度。

有限差分使用相对误差与绝对误差容限，例如 `math.isclose`；不能要求浮点逐位相等。可选对照测试与基础测试分开，基础验收不要求安装 torch。

对照自己的实现时，导入 `tianyi_micrograd.engine.Value`。若直接运行原仓库测试，导入的仍是原版，不能作为自己的实现通过的证据。

### 第 06 课：Module 与 Neuron

- 实现 `parameters()`、`zero_grad()`、权重、偏置、`__call__`。
- 先用固定参数验证线性输出，再启用随机初始化和可选 ReLU。
- `Neuron(3)` 有 `4` 个参数；参数列表须返回原来的对象。
- 验收：给定权重的前向与参数梯度；清梯度保留参数值；激活开关有效。

清梯度只把参数的 `grad` 归零，不重新生成权重，不更改 `.data`。

### 第 07 课：Layer 与 MLP

- 实现多神经元、层间传递与参数列表展开。
- 对齐参考返回约定：单输出层返回一个 `Value`，多输出层返回列表。
- 最后一层使用线性输出，其余层使用 ReLU。
- 验收：`MLP(3,[4,4,1])` 有 `41` 个参数，输出为一个 `Value`；参数更新作用于模型本身。

首版采用合法且匹配的输入长度，避免依赖 `zip()` 的静默截断。参考单输出层返回标量，宽度为 `1` 的中间层直接接下一层存在接口限制；主线示例只把单输出放在最后一层，先把这个约定讲清楚。泛化输入检查或统一列表返回属于后续明确讨论的改动。

### 第 08 课：第一次完整训练

- 先用无激活的单神经元拟合 `y=2x+1`，数据固定为 `x=-1,0,1`。
- 权重和偏置从 `0` 起步，用均方误差与普通梯度下降。
- 每轮执行：重新前向计算损失 → 清空参数梯度 → 反传 → 更新参数数值。
- 更新用 `p.data -= learning_rate * p.grad`，避免通过 `Value` 运算把更新步骤接回计算图。
- 验收：初始平均损失为 `11/3`，`dw=-8/3`、`db=-2`；训练后损失明显下降，参数接近 `2` 和 `1`。

先验证一次更新的方向，再观察多轮收敛。此实验只用自己的引擎和 Python，不依赖 PyTorch、NumPy 或数据集库。不要把“训练能下降”当成前面梯度单测的替代品。

### 第 09 课：双月分类与参考 demo 复现

- 按参考 notebook 使用双月数据、`-1/+1` 标签和 `MLP(2,[16,16,1])`。
- 解释间隔损失 `max(0,1-y*score)`、L2 正则和学习率变化。
- 模型参数个数为 `48+272+17=337`。
- NumPy、scikit-learn、Matplotlib 分别用于数据处理、数据生成和绘图；前向、反传、参数更新都使用自己实现的代码。
- 验收：记录随机种子、初始与最终损失/准确率，绘制决策边界，解释训练准确率的含义。

准确率不承诺在所有环境、种子下完全一致，也不能只凭一张图断言实现正确。第一轮先固定数据与全量训练，不同时增加小批量逻辑。没有独立测试集时，明确报告为训练集准确率。

### 第 10 课：计算图可视化与项目收尾

- 先用文本查看数值、梯度和节点连接，再选择引入 Graphviz。
- 若绘图，解释 Python 的 graphviz 包和系统 `dot` 程序是两项不同依赖；需要时由用户安装。
- 验收：能从小图追踪一个梯度，复述整个实现的工作过程。
- 整理运行入口、依赖和支持范围；需要打包时再手动增加工程配置。
- 若复制或分发参考实现的代码，按其 MIT 许可证保留相应版权和许可声明；相关文件由用户编辑。

## 5. 后续每课的写作格式

一篇教学文档至少包含：

1. **起点与目标**：已有哪些能力，本课只增加什么。
2. **文件清单**：用户需要创建或修改的绝对路径；区分新增方法与替换方法。
3. **小例子**：具体输入、预期输出、手算推导。
4. **逐步手写**：按可理解的小段组织代码，解释新出现的 Python 语法。
5. **验证方法**：准确的工作目录、命令、预期结果与误差容限。
6. **易错定位**：现象、可能原因、如何缩小范围。
7. **验收问题**：既检查能否运行，也检查是否理解。

示例必须说明放置位置和缩进。代码展示采用增量片段时，不再附一份容易重复粘贴的整文件版本。若必须提供整文件，明确它与拆解片段二选一，不让用户把两者拼在一起。

不提前引入尚未讲解的方法；测试只使用当前课已经完成的能力。学习所需的 Python 类、特殊方法、集合、闭包、递归、列表推导、继承和可调用对象，都在第一次实际使用时讲解。
